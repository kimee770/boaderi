# boaderi

Responsive Next.js design system playground built with TypeScript, Tailwind CSS, and pnpm.

## Requirements

- Node.js 20.9 or newer
- pnpm 10 or newer

## Install

```bash
pnpm install
```

## Run locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the component playground.

## Checks

```bash
pnpm lint
pnpm build
```

The home screen demonstrates the project’s cyan and neutral color tokens, button variants, card layouts, and input styling. The official shadcn preset `b1haoS` still needs to be applied once the environment can reach `ui.shadcn.com`.
